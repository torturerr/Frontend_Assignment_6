Brief Summary of Work Process

In this assignment, I learned and applied jQuery to build an interactive personal portfolio website:
1. Setup & Selectors (Part 1): Configured jQuery 3.7.1 via CDN inside "$(document).ready()". Implemented headline manipulation via ".text()" / ".css()" and engineered responsive Light and Dark theme switching.
2. jQuery Effects (Part 2): Applied visibility controls (".hide()", ".show()", ".toggle()"), opacity transitions (".fadeIn()", ".fadeOut()", ".fadeToggle()") for local art assets, and smooth collapsible accordion panels using ".slideToggle()", ".slideUp()", and ".slideDown()".
3. DOM Manipulation (Part 3): Handled list manipulation with ".append()", ".prepend()", and ".remove()" with empty-value prevention. Implemented dynamic attribute mutation (".attr()") for social links and created a real-time form preview using ".val()" and ".on('input')".
4. Animations (Part 4): Built interactive skill progress bars animated from zero width to specific percentages and toggling back using jQuery's ".animate()" method.
